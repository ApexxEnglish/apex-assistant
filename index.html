This is a working demo of the chat widget — it opens automatically after 30 seconds, or click the mark icon in the corner anytime. It answers course/pricing questions and doubles as a conversation partner: when a student writes a sentence with a mistake, it marks the error and shows the fix inline, like a teacher's note in the margin.

Use the TR / EN / RU switcher inside the widget to change the interface and explanation language (Turkish first, and the default). English practice sentences and corrections always stay in English — only the assistant's own explanations and support answers switch, so a Turkish or Russian-speaking student gets help in their own language.

Note on embedding: this widget calls /api/chat, a small backend function that holds your free Gemini API key. Deploy the whole project (this repo) to Vercel, then either host your full site there, or point the fetch URL at your deployed Vercel domain if the widget lives on a different site. See README.md for the full setup.
